## 📁 Sobre este repositório

Este é o repositório do meu site pessoal (`cfcedraz.github.io`), servido pelo **GitHub Pages**.

- **`index.html`** — página única, responsiva, em HTML/CSS/JavaScript puro (sem frameworks nem build);
- Tipografia [Inter](https://fonts.google.com/specimen/Inter) e ícones [Font Awesome](https://fontawesome.com/) via CDN;
- O progresso da graduação é calculado dinamicamente em JavaScript;
- **Nenhum dado sensível**: o repositório não contém credenciais, tokens, variáveis de ambiente nem dados internos de empresas (ver `.gitignore`).

### Rodar localmente

```bash
git clone https://github.com/cfcedraz/cfcedraz.github.io.git
cd cfcedraz.github.io
python -m http.server 8000   # ou simplesmente abra o index.html no navegador
```
